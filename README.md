# BLOCK//DROP — 브라우저 테트리스

브라우저에서 플레이하는 싱글 플레이 테트리스입니다. WebAudio API가 코로베이니카 멜로디를 BGM으로 연주합니다. FastAPI + SQLite 백엔드와 연동하면 이메일 회원가입·로그인, 게임마다 기록 저장, 전체 최고 점수와 랭킹 표시를 지원합니다.

## 실행하고 접속하기

### 백엔드와 함께 실행 (회원·기록·랭킹)

```bash
cd backend
uv venv .venv && uv pip install -p .venv/bin/python -r requirements-dev.txt   # 최초 1회
.venv/bin/uvicorn app.main:app --reload
```

브라우저에서 http://127.0.0.1:8000/ 에 접속해 이메일로 회원가입 또는 로그인한 뒤 플레이합니다. 로그인해야 게임을 시작할 수 있고, 게임이 끝날 때마다 기록이 저장됩니다. API 문서는 http://127.0.0.1:8000/docs 에 있습니다. 자세한 구축 과정은 `exercise.md`를 참고하세요.

### 백엔드 없이 실행 (오프라인 모드)

`index.html`을 브라우저로 직접 열거나 GitHub Pages(https://hdg-lds.github.io/tetris/)로 접속하면 백엔드가 없으므로 로그인 없이 게임만 할 수 있고, 기록은 저장되지 않습니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 블록 이동 |
| `↓` | 소프트 드롭 (내릴 때마다 1점) |
| `↑` 또는 `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `Space` | 하드 드롭 (내려간 칸마다 2점) |
| `P` | 일시정지 또는 재개 |
| `Enter` | 시작 또는 게임 종료 후 재시작 |
| `R` | 새 게임 시작 |

휴대폰에서는 화면 아래 고정 조작 버튼을 사용합니다. 좌우 이동과 아래 방향은 누르고 있으면 반복되며, 회전은 한 번 눌러 동작합니다. `DROP`은 하드 드롭, 시작·일시정지 버튼은 각각 게임 시작·재개와 일시정지·재개를 담당합니다.

상단 또는 모바일 조작 패널의 **BGM ON/OFF** 버튼으로 코로베이니카 음악을 켜거나 끌 수 있습니다. WebAudio로 생성하므로 음악 파일이나 네트워크 연결은 필요하지 않습니다. 게임을 일시정지하거나 끝내면 음악도 멈춥니다.

## 게임 규칙

- 10 × 20 보드에서 7종 블록이 내려옵니다. 다음 블록을 미리 볼 수 있습니다.
- 한 번에 지운 줄 수에 따라 100, 300, 500, 800점에 현재 레벨을 곱해 점수를 얻습니다.
- 10줄을 지울 때마다 레벨이 오르며, 블록 낙하 간격은 800ms에서 시작해 레벨마다 15%씩 짧아집니다. 최소 간격은 80ms입니다.
- 블록이 쌓여 새 블록을 놓을 수 없으면 게임이 끝납니다.
- 데스크톱은 키보드, 작은 화면은 터치 조작을 지원하며 게임 방법을 랜딩 화면에서 안내합니다.

## 파일 구성

- `index.html` — 게임 화면, 스타일, UI·로그인 연동 스크립트
- `src/tetris-core.js` — 테스트 가능한 순수 게임 로직
- `src/api-client.js` — 백엔드 API 호출 (회원, 기록, 랭킹)
- `tests/` — Jest 유닛 테스트 (`npm test`)
- `backend/` — FastAPI + SQLite 백엔드와 pytest 테스트
- `exercise.md` — 백엔드 구축·연동 실습 과정
- `PLAN.md` — 구현 계획
